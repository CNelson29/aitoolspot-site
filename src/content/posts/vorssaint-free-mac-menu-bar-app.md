## What it is

[Vorssaint](https://github.com/vorssaint/vorssaint-utils) is a free, open-source (GPL-3.0-or-later) macOS menu bar app that bundles the functionality of a dozen separate paid utilities into one icon. It requires macOS 14 Sonoma or newer, and it's Apple Silicon only — there's no Intel Mac support.

It's not an AI tool, and we're not pretending it is — it's a genuinely useful piece of free software worth knowing about if you're on a modern Mac.

## What it actually does

- **Sound:** per-app volume mixer with individual sliders, per-app audio output routing, microphone tools
- **System monitoring:** CPU/GPU/memory/swap usage with history graphs, temperature monitoring with optional fan control, battery health, network speed test
- **Window & Dock:** enhanced app switcher with live thumbnails, window snapping (halves, thirds, sixths, corners), dock preview and click customization
- **Input:** text snippet expansion, mouse remapping, key debounce for worn keyboards
- **Clipboard & files:** local clipboard history with pinned items, a "file shelf" for parking files mid-drag
- **Capture:** screenshots with annotation, screen recording, on-screen text extraction, color picker
- **System tools:** command bar / app launcher, Homebrew integration, an uninstaller that also removes leftover files

## Install

```
brew install --cask vorssaint
```

Or download the disk image directly from the repo. No account, no telemetry — permissions are opt-in and explained individually.

## Worth knowing

It's free with an optional "Buy Me a Coffee" donation — no paywalled tier holding back core features. If you're currently paying for 2-3 separate menu bar utilities to cover volume control, window snapping, and clipboard history, this genuinely consolidates them.
