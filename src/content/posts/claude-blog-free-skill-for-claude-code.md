## What it is

[claude-blog](https://github.com/AgriciDaniel/claude-blog) is a free, MIT-licensed skill suite for [Claude Code](https://claude.com/claude-code) that writes, optimizes, audits, translates, and refreshes blog content. It's not a standalone app — it only works if you already use Claude Code, so if that's not part of your workflow, this isn't the tool for you.

The core idea: instead of a single "write me a blog post" prompt, it runs a five-stage delivery pipeline that scores every draft against a 100-point rubric across content quality, SEO, and technical checks, and blocks delivery below a 90 score — iterating up to three times before flagging it for human review instead of shipping something mediocre.

## What's included

- Writing, rewriting, and outline/brief generation
- SEO validation and AI-citation-readiness auditing
- Fact-checking against cited sources
- Multilingual translation with hreflang handling
- Style-learning from sample posts to match an existing author's voice
- Editorial calendars, topic clustering, and content-decay detection from Search Console data

Per the repo, it renders to Next.js MDX, Astro, Hugo, Jekyll, WordPress, Ghost, 11ty, and Gatsby.

## Worth knowing

This is a genuinely full-featured suite — the same category of tool this very site uses internally for its own content pipeline. If you're already a Claude Code user publishing blog content, it's a real, free option worth trying instead of building your own prompts from scratch.
